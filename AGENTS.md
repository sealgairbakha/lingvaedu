# Работа над LingvaEdu

## Контекст проекта

LingvaEdu — действующая LMS для администраторов, наставников и учеников: курсы,
редактор и прохождение уроков, проверка заданий, группы, пользователи, отчёты,
календарь и видеокомнаты. Основной язык интерфейса — русский; учебный контент
может быть многоязычным. Точность данных, понятность действий и скорость
повседневной работы важнее декоративных эффектов.

Стек: React 19, TypeScript, Vite, React Router, обычный CSS, Supabase и Vercel
Functions. Сначала изучай существующие компоненты и `package.json`.

## Навыки дизайна

По просьбе пользователя в `.agents/skills/` установлены навыки из
`emilkowalski/skills`, `pbakaus/impeccable` и `Leonxlnx/taste-skill`.
Перед работой над UI прочитай [контекст и правила применения](docs/design-skills.md),
затем подходящий `SKILL.md` и необходимые ему справочные файлы:

- Основная работа над UX/UI, доступностью, адаптивностью и состояниями:
  [impeccable](.agents/skills/impeccable/SKILL.md).
- Качество компонентов, взаимодействия и принципы анимации:
  [emil-design-eng](.agents/skills/emil-design-eng/SKILL.md).
- Реализация новой анимации:
  [animate](.agents/skills/animate/SKILL.md).
- Запрошенное ревью существующей анимации:
  [review-animations](.agents/skills/review-animations/SKILL.md).
- Запрошенное улучшение оформления существующей страницы:
  [redesign-existing-projects](.agents/skills/redesign-existing-projects/SKILL.md).

Не загружай все навыки и справочники одновременно. Для серверных задач без
изменений интерфейса они не нужны. Установка навыков сама по себе не является
заданием на переделку страниц. Применяй рекомендации в пределах текущей задачи.

## Правила применения к LMS

- Для рабочих экранов выбирай режим Impeccable `Operate`, для чтения материалов
  урока — `Read`. Маркетинговые приёмы применяй только к маркетинговым страницам.
- При обычной доработке сохраняй существующую идентичность: Onest, текущие
  цветовые токены, навигацию, светлую и тёмную темы. Меняй визуальное направление,
  когда это следует из задания пользователя, а не из общего запрета в чеклисте.
- Переиспользуй CSS-переменные и компоненты. Не добавляй Tailwind, UI-фреймворк,
  шрифты или библиотеку анимации только потому, что они приведены в примере навыка.
- Для данных используй реальные состояния загрузки, пустого результата и ошибки.
  Не заменяй настоящие показатели, имена, даты и учебный контент вымышленными ради
  оформления. Декоративные изображения не должны мешать работе с уроком.
- Сохраняй видимый клавиатурный фокус, семантику элементов, доступные названия,
  управление с клавиатуры и touch-устройств. Изменения движения должны учитывать
  `prefers-reduced-motion`; hover-движение ограничивай устройствами с hover.
- Анимация должна объяснять изменение или давать отклик. Для частых действий
  предпочитай мгновенную реакцию. Для простых переходов достаточно CSS;
  указывай конкретные свойства вместо `transition: all`.
- Проверяй каскад по фактическому порядку импортов в `src/main.tsx`:
  поздние стили могут переопределять ранние. Не дописывай очередное глобальное
  переопределение без изучения существующих правил.

## Проверки

После изменений приложения выполняй соответствующие проверки из `package.json`.
Перед публикацией обязателен `npm run check` и `npm audit --audit-level=high`
согласно README. Для изменений UI проверяй затронутый сценарий в браузере,
мобильную и настольную ширину, обе темы и доступность управления.
Не утверждай, что выполнены проверки, которые фактически не запускались.

При обновлении сторонних навыков сохраняй лицензии, проверяй содержимое и
обновляй `.agents/skills.lock.json`. Оригиналы навыков хранятся без локальных
правок; адаптация к LingvaEdu находится в этом файле и `docs/design-skills.md`.
