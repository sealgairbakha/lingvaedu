# Lingva Edu

Интерактивная платформа компании Lingva для изучения английского, русского и казахского языков.

## Возможности

- кабинет ученика и карта прогресса;
- интерактивные уроки и задания;
- адаптивный интерфейс для компьютеров, планшетов и телефонов;
- административный конструктор Unit'ов и уроков;
- управление пользователями, курсами и подписками.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```
