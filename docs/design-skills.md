# Навыки дизайна для LingvaEdu

Подключены 7 сентября 2026 года локально для этого проекта, в `.agents/skills/`.
Это инструкции для агента и их справочные материалы. Они не импортируются
приложением и не добавляют зависимости в `package.json`.

## Что выбрано

| Источник | Установленные навыки | Применение |
| --- | --- | --- |
| [Emil Kowalski](https://github.com/emilkowalski/skills) | `emil-design-eng`, `animate`, `review-animations` | Детали компонентов, назначение анимации, отклик, длительность и проверка движения |
| [Impeccable](https://github.com/pbakaus/impeccable) | `impeccable` с комплектом справочников и скриптов | UX, визуальная иерархия, адаптивность, доступность, состояния, типографика и проверка интерфейса |
| [Taste Skill](https://github.com/Leonxlnx/taste-skill) | `redesign-existing-projects` | Анализ и точечное улучшение существующих экранов с сохранением функциональности |

Основной `design-taste-frontend` в просмотренной версии Taste Skill предназначен
для лендингов, портфолио и редизайнов и явно исключает dashboards, data tables
и multi-step product UI. Поэтому для LMS выбран `redesign-existing-projects`.
Навыки Swift, Expo, генерации изображений и отдельные стилистические направления
не устанавливались: они не нужны текущему стеку и задаче подключения.

## Контекст, подтверждённый кодом

- Пользователи: администраторы, сотрудники/наставники и ученики. Доступ и действия
  зависят от роли; дизайн не должен обходить проверки прав.
- Рабочие сценарии: управление курсами и группами, подготовка уроков, обучение,
  проверка заданий, просмотр отчётов, календарь и видеозвонки.
- Язык оболочки — русский. В уроках и заданиях есть многоязычный контент;
  учитывай длинные строки, кириллицу, числа и переносы.
- React 19 + TypeScript + Vite + React Router; стили написаны обычным CSS.
  Шрифт Onest подключён в `src/main.tsx`, переменная `--font-sans` уточняется
  в `src/styles/typography.css`.
- Основные токены в `src/styles/index.css`: `--nav`, `--ink`, `--muted`,
  `--line`, `--bg`, `--card`, `--purple`, `--lime`. Фиолетовый и лаймовый уже
  входят в оформление продукта; общий совет избегать шаблонного фиолетового
  оформления сам по себе не является основанием для смены палитры.
- Тема задаётся через `html[data-theme]`. Общие фокус и состояния находятся
  в `src/styles/platform.css`; адаптивные правила — в `src/styles/responsive.css`.
  Порядок импортов в `src/main.tsx` определяет каскад; `platform.css` сейчас
  импортируется после `responsive.css`.
- Существующие `PageState`, `ConnectionNotice` и `ErrorBoundary` задают подход
  к загрузке, ошибкам и восстановлению. Сначала проверяй возможность их повторного
  использования.

Это описание реализации, а не результат визуального аудита и не новый брендбук.
Возраст учеников, брендовые запреты и конкретные устройства не установлены;
не выдавай предположения о них за требования пользователя.

## Как использовать

Для новой задачи выбирай основной навык по таблице, прочитай его полностью и
подключай дополнительные справочники только по необходимости. Проектный контекст
и явная задача пользователя определяют, какие рекомендации уместны.

Примеры запросов:

- «Используй impeccable: проверь адаптивность страницы курсов».
- «Используй redesign-existing-projects: улучши иерархию редактора урока».
- «Используй animate: добавь короткий отклик при раскрытии панели».
- «Используй review-animations: проверь анимацию модального окна».

Impeccable 4.2.2 поставляется с Windows launcher
`.agents/skills/impeccable/scripts/impeccable.cmd`. При первом применении навыка
его setup запускает `context` из корня проекта; launcher при необходимости
скачивает собственный движок в пользовательский кэш. Для текущего подключения
launcher и его команды не запускались, hooks не настраивались. Установка файлов
проверена отдельно; выполнение движка этим не подтверждается.

- Impeccable: `dbdc470e70dbbda69f9b78ee38bc38ea1d3560b9`.
- Taste Skill: `ccbc15639c97057cbfcf32ecebc38ef716e4bb37`.

Пути источников и SHA-256 каждого установленного файла записаны в
[манифесте](../.agents/skills.lock.json). Лицензии и уведомления находятся
в `.agents/third-party/`. Файлы исходных навыков не изменены.

Обновляй выбранный навык адресно: изучи новый коммит, замени полный комплект
его файлов из исходного пути, сохрани лицензии, обнови коммит и хэши в манифесте.
Проверь ссылки на справочники и изменения требований. Автоматического обновления
на `main` нет. Сторонние файлы навыков исключены из ESLint приложения.
